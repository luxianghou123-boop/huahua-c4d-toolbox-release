# 花花智能建模-AI端 v28.284

- 新增程序化彩色半调：形状渐变网点与图片半调，支持单色、双色渐变和原图彩色（图片模式）。

- 保留表格、字体搜索、导出、厚度、授权、CDK 和后台更新逻辑，不新增自动状态轮询。
